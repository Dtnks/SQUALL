SQUALL survival prediction on TCGA-CESC

An end-to-end tutorial for extracting slide embeddings with a pretrained SQUALL checkpoint and training a five-fold attention-based multiple-instance learning model with Cox loss.

1. TilesTCGA-CESC image patches
2. EmbeddingsSQUALL slide features
3. Survival modelABMIL + Cox loss

1. Requirements and directory layout

This workflow assumes that TCGA-CESC slides have already been tiled and that overall-survival labels have been split into five JSON files. Run all commands from the SQUALL repository root.

SQUALL/
├── finetune.py
├── abmil.py
├── scripts/
│   ├── survival/get_embedding/
│   └── survival/cesc/
├── checkpoints/
├── data/TCGA-CESC-tiles/
├── labels/TCGA-CESC-survival/
└── features/TCGA-CESC/

Define site-specific locations once. Do not hard-code user names or private home-directory paths in files intended for publication.

export SQUALL_ROOT=/path/to/SQUALL
export TILE_ROOT=/path/to/TCGA-CESC-tiles
export FEATURE_ROOT=/path/to/features/TCGA-CESC
export LABEL_ROOT=/path/to/TCGA-CESC-survival
export SQUALL_CKPT=/path/to/squall-pretrained.pth

cd "$SQUALL_ROOT"

2. Extract SQUALL embeddings

2.1 Dataset configuration

Create scripts/survival/get_embedding/HistMolABMIL_getembedding.yaml:

NAME: HistMolABMIL_embedding
DATA_PATH: /path/to/TCGA-CESC-tiles

2.2 Embedding configuration

Create scripts/survival/get_embedding/large_abmil_RNA.yaml. The architectural values must match the pretrained checkpoint.

dataset:
  train:
    _base_: scripts/survival/get_embedding/HistMolABMIL_getembedding.yaml
    others:
      if_abmil: false
      if_embedding: true
      if_benchmark: false
      subset: train
      sample_num: 32
      bs: 1024
  val:
    _base_: scripts/survival/get_embedding/HistMolABMIL_getembedding.yaml
    others:
      if_abmil: false
      if_embedding: true
      if_benchmark: false
      subset: test
      sample_num: 32
      bs: 1024

model:
  NAME: StormClassification
  img_size: 224
  expr_size: 56
  expr_chans: 15757
  down_sample: 16
  mask_ratio: 0.5
  embed_dim: 1024
  depth: 24
  merge_layer_depth: 16
  drop_path_rate: 0.1
  num_heads: 16
  pos_type: mlp
  decoder_depth: 4
  PE_type: RPB
  if_rpb: true
  if_PE: false
  cls_dim: 18
  loss: CE

total_bs: 1024
step_per_update: 1
max_epoch: 300
grad_norm_clip: 10
Compatibility note. Some code versions retain the internal class name StormClassification. Keep the class name expected by your installed repository even when the public model/tutorial name is SQUALL.

2.3 Run feature extraction

Create scripts/survival/get_embedding/get_embedding_cesc.sh:

#!/usr/bin/env bash
set -euo pipefail

: "${SQUALL_CKPT:?Set SQUALL_CKPT first}"
: "${FEATURE_ROOT:?Set FEATURE_ROOT first}"

CUDA_VISIBLE_DEVICES=0 python finetune.py \
  --config scripts/survival/get_embedding/large_abmil_RNA.yaml \
  --get_embedding \
  --exp_name getembedding_TCGA_CESC_SQUALL \
  --ckpts "$SQUALL_CKPT" \
  --save_dir "$FEATURE_ROOT"

Activate the environment and run the extraction script from the repository root:

source /path/to/miniconda3/etc/profile.d/conda.sh
conda activate SQUALL

export SQUALL_ROOT=/path/to/SQUALL
export FEATURE_ROOT=/path/to/features/TCGA-CESC
export SQUALL_CKPT=/path/to/squall-pretrained.pth

cd "$SQUALL_ROOT"
bash scripts/survival/get_embedding/get_embedding_cesc.sh

3. Configure five-fold survival training

3.1 Fold-specific dataset files

For each fold k = 1,...,5, create HistMolABMIL_lowres_tissue_foldk.yaml:

NAME: TCGASlideEmbedding
DATA_PATH: /path/to/features/TCGA-CESC/train
label_dict: /path/to/TCGA-CESC-survival/Survival_TCGA_CESC_fold1.json

Change only the label filename for folds 2–5. Each JSON file must define the training/test split and the survival time/event fields expected by the dataset loader.

3.2 ABMIL–Cox configuration

Create one configuration per fold. The following is the fold-1 template:

abmil_type: Survival
fwd_type: benchmark
accumulation_steps: 32

dataset:
  train:
    _base_: scripts/survival/cesc/HistMolABMIL_lowres_tissue_fold1.yaml
    others:
      bs: 1024
      if_abmil: true
      if_benchmark: true
      if_embedding: true
      sample_num: 32
      subset: train
  val:
    _base_: scripts/survival/cesc/HistMolABMIL_lowres_tissue_fold1.yaml
    others:
      bs: 1024
      if_abmil: true
      if_benchmark: true
      if_embedding: true
      sample_num: 32
      subset: test

model:
  NAME: ABMIL
  cls_dim: 1
  embed_dim: 1024
  loss: COX
  PE_type: RPB
  PE_RPB_fixed: false
  if_rpb: false
  if_PE: false

optimizer:
  type: AdamW
  freeze: false
  kwargs:
    lr: 2e-4
    weight_decay: 1e-5
    betas: [0.9, 0.999]

scheduler:
  type: CosLR
  kwargs:
    epochs: 100
    initial_epochs: 5.0
    lr_min: 2e-4
    warmup_lr_init: 2e-4
    cycle_limit: 1

max_epoch: 100
total_bs: 4096
step_per_update: 1
grad_norm_clip: 10
SettingRole
cls_dim: 1Produces one continuous risk score per slide/patient.
loss: COXOptimizes the Cox partial likelihood for censored survival data.
if_embedding: trueLoads precomputed SQUALL features rather than raw image tiles.
sample_num: 32Controls the number of instances sampled for each bag according to this codebase's loader.
accumulation_steps: 32Accumulates gradients to obtain the requested effective batch behavior.

3.3 Run one fold

CUDA_VISIBLE_DEVICES=0 python abmil.py \
  --config scripts/survival/cesc/large_abmil_lowres_tissue_fold1.yaml \
  --exp_name SQUALL_TCGA_CESC_survival_fold1 \
  --seed 2 \
  --freeze_all
Important: do not leave a trailing backslash after --freeze_all. A backslash means that the shell command continues on the next line.

4. Run all five folds

The following Bash script runs the five folds sequentially and writes separate log files for each fold:

#!/usr/bin/env bash
set -euo pipefail
source /path/to/miniconda3/etc/profile.d/conda.sh
conda activate SQUALL

export SQUALL_ROOT=/path/to/SQUALL
cd "$SQUALL_ROOT"

mkdir -p logs

for fold in 1 2 3 4 5; do
  echo "Running fold ${fold}"
  CUDA_VISIBLE_DEVICES=0 python abmil.py \
    --config "scripts/survival/cesc/large_abmil_lowres_tissue_fold${fold}.yaml" \
    --exp_name "SQUALL_TCGA_CESC_survival_fold${fold}" \
    --seed 2 \
    --freeze_all \
    > "logs/CESC_survival_fold${fold}.out" 2>&1
done

Save it as run_cesc_survival_5fold.sh, then run:

mkdir -p logs
chmod +x run_cesc_survival_5fold.sh
./run_cesc_survival_5fold.sh
Tip: the folds run sequentially on GPU 0. To use another GPU, change CUDA_VISIBLE_DEVICES=0. Ensure that no OV dataset or configuration remains in a CESC experiment.

5. Validation and troubleshooting

Before survival training

  • Confirm that FEATURE_ROOT/train contains embeddings for the expected CESC cases.
  • Confirm that patient/slide identifiers match the keys in every fold JSON.
  • Check that the feature dimension is 1024, matching embed_dim.
  • Check that survival time is positive and event status uses the convention expected by abmil.py.

During training

tail -f logs/CESC_survival_fold1.out

# Check GPU utilization in another terminal when needed
nvidia-smi

Recommended report

Report the concordance index for each fold and summarize performance as mean ± standard deviation across all five folds. Keep the split JSON files, random seed, checkpoint identity, and software revision fixed for reproducibility.

Pipeline summary: extract CESC slide embeddings once, verify that feature identifiers match the survival labels, then train five independent ABMIL–Cox models using fold-specific JSON splits.
